# Assets

This folder contains the app icons and images.

## Required Files

You need to add the following image files:

1. **icon.png** (1024x1024) - App icon
2. **splash.png** (1284x2778) - Splash screen image
3. **adaptive-icon.png** (1024x1024) - Android adaptive icon foreground
4. **favicon.png** (48x48) - Web favicon
5. **notification-icon.png** (96x96) - Notification icon (Android)

## Recommendations

- Use a shield or rescue-themed icon
- Primary color: Red (#DC2626)
- Keep important content in the center of adaptive-icon.png

## Quick Setup

For testing, you can use placeholder images. Create simple colored squares:

1. Create a 1024x1024 red square with "SALBA" text for `icon.png`
2. Create a 1284x2778 red image with centered logo for `splash.png`
3. Copy `icon.png` to `adaptive-icon.png`
4. Create a 48x48 version for `favicon.png`

You can generate these using online tools like:
- https://www.canva.com
- https://www.figma.com
- https://makeappicon.com
